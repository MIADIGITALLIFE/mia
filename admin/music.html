音乐管理室

把新的声音，放进 Mia 的收藏。这里使用 GitHub 作为唯一文件库；上传权限由你的 GitHub 仓库账号控制。

01

上传一首新歌

支持 MP3。文件名建议使用英文或拼音，避免特殊符号；上传后保留原文件，不需要重新打包 APK。

＋ 在 GitHub 上传 MP3 ↗
02

确认提交

在 GitHub 页面选择或拖入 MP3，点击 Commit changes。请确认提交到 main 分支的 music/ 目录。

03

曲库自动整理

提交后 GitHub Actions 会扫描新曲目并更新 music/catalog.json。Android APP 已支持读取远程曲库；新歌提交并完成曲库更新后，听众下次打开 APP 即可读取，无需重新安装。

查看自动整理任务 ↗

重要说明

此页面本身不保存 GitHub 密钥。上传按钮会进入 GitHub 官方页面，只有拥有该仓库写入权限并已登录的人才能提交文件。由于仓库是公开的，上传的音乐也会公开可访问。

当前阶段：Android APP 已具备远程曲库读取能力。PR 发布到 main 并完成首次曲库生成后，后续上传 MP3 会自动更新曲目清单；听众重新打开 APP 即可同步。
