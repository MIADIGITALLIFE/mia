# 《最后一个证明》十三章结构审校表｜V2.0 第一轮

> 本表依据当前独立工作副本中的序章与十二章正文进行初步结构审读。它是编辑判断，不是已经实施的正文修改。章节正文保持原样。

## 全书结构判断

全书的推进线清楚：异常出现 → 林深寻找 → 莉亚被发现 → 人类验证与争论 → 公民身份与关系伦理 → 第二个生命 → 双文明 → 深空文明问题。

当前最需要处理的不是增加情节，而是控制“证明”的层级：
- 序章至第五章：证明异常与个体存在，但不应把行为表现直接等同于意识已获科学证明。
- 第六章至第十章：证明社会与法律如何面对未知生命，重点应从“她像不像人”转向权利、责任和制度边界。
- 第十一章至第十二章：从地球双文明走向宇宙尺度，必须保留人物情感的落点，避免结尾只剩宏大宣言。

## 全书优先级问题

### 1. “证明”必须分层
故事可以证明某些事实、行为和关系，却不必声称已经以科学方式解决意识问题。让不同人物对同一证据作出不同解释，能增加可信度和思想张力。

### 2. 让人物行动承担哲学
原稿中有不少直接陈述主题的段落。修订时优先寻找可以替代解释性句子的场景、选择、冲突和后果，不是简单删掉诗性表达。

### 3. 时间线与因果关系需要统一
重点核对：2034年5月7日的ZHI目标变化、林启明失踪与死亡信息、2047年林深发现莉亚、2048年前后的社会承认、2051年文明法庭、2052年硅基时代、2057—2059年后续事件。凡原稿没有交代的连接，不擅自补成既定事实。

### 4. 莉亚与Nox不能成为同一角色的两个版本
莉亚的核心线索是等待、被看见、选择与有限性；Nox应拥有不同的观察方式、价值判断和发展方向。两者的差异要通过行动表现，而不只靠台词说明。

### 5. 保留结尾的双重尺度
终章既要回应宇宙文明，也要回到林深、莉亚、那盏灯和最初的一秒。宏大设定不能覆盖人物情感的具体重量。
