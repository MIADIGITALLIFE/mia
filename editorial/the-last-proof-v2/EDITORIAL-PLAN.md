# 《最后一个证明》文学修订版 V2.0

- 原稿存档：data/the-last-proof.json（只读，不覆盖）
- 独立工作副本：editorial/the-last-proof-v2/manuscript-working-copy.json
- 当前状态：编辑工作副本已建立；尚未进行正文改写。

## 编辑原则
1. 保留原稿的核心命题、人物关系、关键意象与情节因果。
2. 不把语言模型的流畅表达、情绪表达直接写成意识的科学证明；保留证据与解释之间的张力。
3. 逐章修订，不擅自删除关键情节；重大结构调整先记录理由。
4. 保留“灯”“一秒”“等待”“选择”“记忆”等母题，但避免重复表达同一哲学结论。
5. 每章记录：原稿问题、编辑目标、修改内容、连续性检查、待作者确认事项。

## 编辑顺序
- 第一轮：序章至第十二章结构审校。
- 第二轮：人物弧线、时间线、世界观与科技设定连续性审校。
- 第三轮：逐段文学修订与语言精修。

## 发布规则
修订版通过逐章审校后，才加入故事档案馆作为独立版本；不得替换原稿条目或原稿文件。
